Model Jaringan Saraf Tiruan (Neural Network) modern berbasis Keras 3 untuk memprediksi kategori harga berlian (murah atau mahal) berdasarkan karakteristik dimensi fisiknya.

### Deskripsi Model
Model ini menggunakan arsitektur Keras Sequential dengan pre-processing layer Normalization bawaan TensorFlow versi terbaru untuk menyeragamkan skala fitur angka secara dinamis. Berdasarkan hasil pelatihan selama 10 Epochs, model ini berhasil mencapai akurasi seimbang sebesar 94.5% baik pada data training maupun data validation (kondisi Good Fit).

### Struktur Input
Model menerima input berbentuk tensor numerik float32 dengan dimensi/shape `(None, 5)` yang merepresentasikan fitur fisik berlian secara berurutan: `['carat', 'depth', 'x', 'y', 'z']`.

### Struktur Output
Model mengembalikan skor probabilitas biner lewat 1 output neuron (Dense). Nilai yang mendekati 0 mengindikasikan harga murah (≤ $1000) dan nilai yang mendekati 1 mengindikasikan harga mahal (> $1000).
