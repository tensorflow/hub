# ulya22-designer/diamond-price-classifier/1

Model klasifikasi harga berlian menjadi dua kategori: low dan high.

Model menggunakan lima fitur numerik:
- carat
- depth
- x
- y
- z

Label 0 berarti low (harga <= $1,000).
Label 1 berarti high (harga > $1,000).

## Input
Lima fitur numerik: carat, depth, x, y, dan z.

## Output
Satu nilai logit untuk klasifikasi biner.
Gunakan sigmoid untuk memperoleh probabilitas kelas high.
